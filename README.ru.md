# Titan Quest 2 HC Revival

![Poster](poster.gif)

[🇺🇸 English](./README.md) · [🇷🇺 Русский](./README.ru.md)

Консольная утилита показывает сохранённых персонажей и воскрешает мёртвых персонажей Hardcore, удаляя `m_IsPermanentlyDead` из их файлов `*_Header.sav`. Свойство ищется по имени, без привязки к фиксированному адресу.

## Перед запуском

Обычно работает без этой операции, но для надёжности лучше: закройте Titan Quest 2 и отключите Steam Cloud Sync для игры, чтобы исправленное сохранение не было перезаписано.

## Установка и использование

Скачайте архив для своей платформы из [GitHub Releases](https://github.com/hexqnt/tq2-hc-revival/releases), распакуйте его и запустите программу. Чтобы установить её из исходников, выполните `cargo install --path .` в каталоге проекта. После установки (или указав путь к распакованному файлу) запускайте:

```sh
tq2-hc-revival # Интерактивный выбор персонажа для воскрешения
tq2-hc-revival list # Показать списов всех персонажей
tq2-hc-revival revive Lina # Воскресить персонажа с именем "Lina"
tq2-hc-revival revive --all # Воскресить всех
tq2-hc-revival inspect Lina # Подробные свойства сохранения
tq2-hc-revival restore Lina # Восстановить последнюю резервную копию
```

Программа находит SaveGames автоматически. Без команды она показывает мёртвых персонажей и предлагает выбрать одного по номеру. `list` выводит статус, сложность, уровень, время сохранения, время игры и доступную статистику смертей; отсутствующие поля показаны как `—`. Воскрешать можно только мёртвых персонажей Hardcore. `revive --all` воскрешает всех таких персонажей в выбранном каталоге. Имена с пробелами берите в кавычки, например `revive "My Hero"`.

`inspect` показывает сводку персонажа и найденные свойства с префиксом `m_` в файлах Header, WorldFluff и PlayerLocal. Он расшифровывает простые значения, перечисления, даты и распространённые варианты локализованного текста. Для коллекций выводятся число и тип элементов, для остальных структур — тип и размер в байтах. Неизвестные кодировки отображаются как `—`. `restore` берёт последнюю подходящую копию, созданную при воскрешении, восстанавливает находящиеся в ней файлы персонажа и сохраняет текущие версии в новом каталоге резервной копии. Общие файлы `.bak` и `Saving.sav` не восстанавливаются. Перед восстановлением закройте игру и отключите Steam Cloud Sync.

Если автоматический поиск не сработал или команда нашла несколько каталогов с сохранениями, укажите каталог вручную (параметр работает с любой командой):

```sh
tq2-hc-revival --save-dir "/path/to/SaveGames" revive Hexen
```

Интерактивный режим попросит указать путь, если каталог не найден, или выбрать каталог, если их несколько. Автопоиск проверяет `%LOCALAPPDATA%\TQ2\Saved\SaveGames` в Windows, библиотеки Steam на всех платформах, префиксы Proton в Linux и обычные расположения TQ2, CrossOver и Whisky в macOS.

Перед изменением персонажа программа переносит исходный Header в каталог резервной копии с меткой времени рядом с SaveGames. При воскрешении удаляется только флаг окончательной смерти из Header. Остальные сохранения персонажа, файлы `.bak` и `Saving.sav` остаются без изменений: во вложенных структурах сохранений должны сохраняться корректные размеры сериализованных данных. Для `revive --all` резервная копия создаётся отдельно для каждого персонажа. В `list` нулевые значения статистики из сохранений, воскрешённых предыдущими версиями программы, отображаются как `—`.
